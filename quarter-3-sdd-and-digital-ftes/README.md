## 🛠️ Tools & Libraries Used

- **Claude Code** - General agent with full system access via terminal
- **Claude Code Router (ccr)** - Route Claude Code to free models like Gemini
- **Spec-Kit Plus (SpecifyPlus)** - Spec-driven development toolchain (`specifyplus`, `sp init`)
- **GitHub MCP Server** - Repository access and version control integration
- **Gemini API** - Free-tier model access via Google AI Studio
- **Claude Code Marketplace** - Official and community skill/plugin distribution
- **WSL** - Linux development environment for Claude Code on Windows
- **npm** - Global installs for `@anthropic-ai/claude-code` and `claude-code-router`
- **FastAPI & PostgreSQL** - Finance management system tech stack (Class 8)
- **Gemini CLI & OpenAI Codex** - Cross-vendor agent tooling and skill portability
